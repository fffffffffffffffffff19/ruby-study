# Rails Setup

This guide covers the basic installation and verification of Rails using RubyGems.

## Installing Rails

A **gem** in Ruby is a self-contained package of a library or a program. We can use Ruby's built-in `gem` command to install the latest version of Rails and its dependencies directly from [RubyGems.org](https://rubygems.org/).

Run the following command in your terminal to install Rails globally:
```bash
gem install rails
```

## Verifying the Installation

To confirm that Rails has been installed correctly, check the version number by running:
```bash
rails --version
```

If the installation was successful, the terminal will output the current Rails version (e.g., Rails 7.x.x or newer).
